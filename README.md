# Projenin Adı:Kod-Asistan v0.1

## Projenin Kapsamı:KRİTİK EŞİK
Adım1:Başla
Adım2:Eğer su seviyesi>50 ise 4.Adıma git
Adım3:Değilse,kapakları kapalı tut,saat+1,Adım2 ye git.
Adım4:Tahliye saatini ve kritik su seviyesini yazdır.
Adım5:Bitir.
